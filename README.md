## Descripción
Este formulario forma parte del proceso de evaluación psicológica requerido para la obtención del certificado de idoneidad psicológica exigido por la Subsecretaría de Prevención del Delito, para el ejercicio de cargos de seguridad privada.

El evaluado responde el cuestionario de 30 ítems. Los resultados (puntaje total, subescalas e interpretación) se calculan automáticamente y se envían por correo electrónico al profesional a cargo — el evaluado no visualiza ningún resultado.
